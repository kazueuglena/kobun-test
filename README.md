# 古文テスト

共通テスト古文のための自習用ウェブアプリ。**古文単語 390語／助動詞 31／敬語 45／文法識別 46問**（計512項目）を、Anki 風の間隔反復（SRS）で覚える。

👉 **[https://kazueuglena.github.io/kobun-test/](https://kazueuglena.github.io/kobun-test/)**

サーバーは不要。データはページ自体に埋め込まれていて、学習の記録は各端末のブラウザ（localStorage）に保存される。一度開けばオフラインでも起動する（PWA）。

## 4つのデッキ

| デッキ | 中身 | 出題形式 |
|---|---|---|
| 📖 古文単語 | 頻出古語 390 語。品詞・語義・例文・訳・補足 | フラッシュカード |
| 🔧 助動詞 | 31 語。意味・接続・活用表（6 形）・例文・識別のポイント | フラッシュカード |
| 🎎 敬語 | 45 語。尊敬/謙譲/丁寧・もとの語・敬意の方向 | フラッシュカード |
| 🔍 識別 | 46 問。「なむ」「る・れ」「に」「し」「ぬ・ね」「なり」「たり」「らむ」など | 4 択 |

各項目にレベル 1〜3（最重要／標準／発展）が付いていて、絞り込める。

### 原本ページで絞る

古文単語・敬語の各項目には、『読んで見て聞いて覚える 重要古文単語315』（桐原書店）の**掲載ページ**（`pg`）が付いている。
学習タブの設定にある「📖 重要古文単語315のページで絞る」を押すと、指定したページ範囲の語だけが出題される
（一覧タブの「原本」チップでも同じ絞り込みができる）。学校や自習で「今週はp120〜224」と範囲が決まっているときに使う。
315に載っていない語は `pg` を持たないので、絞り込み中は自動的に外れる。

## 使い方

1. **何をやる** で 4 つのデッキから 1 つ選ぶ
2. **今日のプラン**（🌙 夜のメイン 25 分 / ☀️ 朝の復習 10 分 / ⚡ すきま 5 分 / ⚙️ カスタム）を選ぶ
3. 「▶ 学習を開始」

答えを見たら **もう一度 / 難しい / 普通 / 簡単** の 4 段階で自己評価する。評価に応じて次にその項目が出る間隔が
10分 → 1日 → 3日 → 7日 → 14日 → 30日 → 90日 と伸び、90日をクリアすると「定着」になる。
「もう一度」が 4 回連続した項目は、そのセッション中にすぐ戻ってくる。

キーボード（PC）: `Space` で答えを表示 → `A` もう一度 / `S` 難しい / `D` 普通 / `F` 簡単、`R` 読み上げ、`U` 元に戻す、`Esc` 終了。
識別モードは `1`〜`4` で選択肢を選ぶ。

## タブ

- **学習** — デッキ選択・プラン・出題設定・1日の目標
- **分析** — 今日の達成度、デッキ別の進み具合、直近14日の学習量、これから来る復習の予測、手応えの内訳、完走予測、マイルストーン、学習カレンダー、つまずきワースト15
- **一覧** — 全 512 項目の検索・絞り込み（デッキ／状態／並び順）
- **同期** — 端末間で進捗をマージ（ファイル または コード文字列）

## iPhone にホーム画面から入れる

1. **Safari で**上の URL を開く（Chrome だとホーム画面追加がうまく動かない）
2. 画面が出たら 10 秒ほど待つ（裏でアプリ本体をキャッシュしている）
3. 共有ボタン → 「ホーム画面に追加」
4. ホーム画面のアイコンから起動する

以後は機内モード・電波なしでも起動でき、学習記録も端末に残る。

## 注意

- 学習記録は**端末ごと**に保存される。Mac と iPhone は自動では繋がらないので、合わせたいときは「同期」タブから手動でエクスポート／インポートする。
- プライベートブラウズでは記録が保存されない（アプリ上部に警告が出る）。
- iOS は「長期間まったく開かない PWA」のデータを削除することがある。週 1 回でも起動していれば問題ない。

## ファイル構成

```
index.html              アプリ本体（データ埋め込み・単一ファイル）
items.json              全512項目のデータ（index.html に埋め込まれているものと同じ）
sw.js                   Service Worker（オフライン用キャッシュ）
manifest.webmanifest    PWA マニフェスト
icon-192.png / icon-512.png / apple-touch-icon.png
```

`items.json` の各項目の形は次のとおり。

| デッキ | キー |
|---|---|
| `word` | `q` 見出し / `s` 品詞 / `a` 意味 / `x` 例文 / `xj` 訳 / `n` 補足 |
| `aux` | `q` 助動詞 / `a` 意味 / `s` 接続 / `k` 活用6形 / `t` 活用の型 / `x` 例文 / `xj` 訳 / `n` ポイント |
| `kei` | `q` 語 / `s` 種類 / `a` 訳 / `b` もとの語 / `m` 敬意の方向 / `x` 例文 / `xj` 訳 / `n` 補足 |
| `ident` | `x` 例文 / `w` 傍線部 / `c` 選択肢4つ / `ans` 正解の添字 / `a` 解説 / `n` 判別のコツ / `g` カテゴリ |

共通で `d`（デッキ）・`lv`（レベル1-3）・`no`（通し番号）を持つ。
315に対応する項目はさらに `pg`（原本の印刷ページ）・`bno`（原本の見出し語番号）を持ち、
315から取り込んだ89語には `src315: true` が付く。
データは古典文法・古語辞典の標準的な記述に照らして一度通し検証してある。
